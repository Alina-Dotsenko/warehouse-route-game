# Симулятор ошибок топологии склада (Ozon Tech)

Это интерактивное веб-приложение, созданное для демонстрации различных алгоритмических и топологических ошибок при построении маршрутов на складе.

## Требования
Для запуска на любом компьютере вам понадобится только установленный **Node.js** (рекомендуется LTS версия).

## Как запустить проект локально

1. Распакуйте архив с исходным кодом в любую папку.
2. Откройте терминал (командную строку) в папке проекта (там, где лежит файл `package.json`).
3. Установите зависимости проекта одной командой:
   ```bash
   npm install
   ```
4. Запустите локальный сервер:
   ```bash
   npm run dev
   ```
5. В терминале появится ссылка (обычно это `http://localhost:5173/`). Скопируйте её и откройте в браузере.

## Как собрать проект для хостинга (статика)

Если вы хотите развернуть проект на сервере, чтобы люди заходили по ссылке в интернете (без Node.js):

1. Выполните сборку:
   ```bash
   npm run build
   ```
2. В папке проекта появится папка `dist`. Это полностью готовый, оптимизированный сайт (HTML/CSS/JS).
3. Вы можете загрузить содержимое папки `dist` на любой хостинг (GitHub Pages, Vercel, Nginx и т.д.).

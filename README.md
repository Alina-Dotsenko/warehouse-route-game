# route-lab topology

Интерактивная браузерная игра «Найди ошибку топологии». Игрок сравнивает
получившийся и правильный маршруты сборщика, отмечает неверно настроенные
шкафы на canvas-карте склада и проходит пять уровней.

## Играть

Опубликованная версия: <https://alina-dotsenko.github.io/route-lab-topology/>

Игра полностью статическая: сервер и база данных не требуются. Имя и прогресс
хранятся только в текущем браузере.

## Локальный запуск

```bash
cd app
npm ci
npm run dev
```

## Production-сборка

```bash
cd app
npm ci
npm run build
```

Готовый одностраничный сайт создаётся в `app/dist`. Workflow
`.github/workflows/deploy-pages.yml` автоматически собирает и публикует его в
GitHub Pages после каждого обновления ветки `main`.
